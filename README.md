# Comunidad Activa

Aplicación móvil Android desarrollada en Kotlin para la gestión de eventos comunitarios.

## Descripción

Comunidad Activa permite a los usuarios registrarse, iniciar sesión, crear eventos, consultar actividades disponibles, confirmar asistencia, comentar, calificar eventos y revisar su historial de participación.

## Funcionalidades

- Registro e inicio de sesión con Firebase Authentication.
- Creación de eventos comunitarios.
- Visualización de eventos en lista.
- Detalle de evento.
- Edición y eliminación de eventos por el creador.
- Confirmación de asistencia.
- Comentarios y calificaciones.
- Historial de eventos.
- Perfil de usuario.
- Compartir eventos.
- Notificaciones locales.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- RecyclerView
- CardView
- Glide
- Material Design
